# iLungu Club wp-admin Routing Contract

**Status:** Authoritative

## Canonical Club Routes

iLungu Club backend screens are owned by the iLungu Club top-level wp-admin menu. New Club navigation, actions, form return URLs, and redirects must use the `ilungu-club-*` route family.

- Dashboard: `/wp-admin/admin.php?page=ilungu-club-dashboard`
- Settings: `/wp-admin/admin.php?page=ilungu-club-settings`
- Settings tab: `/wp-admin/admin.php?page=ilungu-club-settings&tab={tab}`
- Manage Members: `/wp-admin/admin.php?page=ilungu-club-manage-members`
- Gallery Administration: `/wp-admin/admin.php?page=ilungu-club-gallery-admin`
- Upload Pages: `/wp-admin/admin.php?page=ilungu-club-upload-pages`
- Menu Manager: `/wp-admin/admin.php?page=ilungu-club-menu-manager`
- Logs: `/wp-admin/admin.php?page=ilungu-club-logs`

Core Settings tabs currently include `branding`, `member-menu`, `features`, `email`, `email-logs`, `email-templates`, `email-queue`, `system-pages`, and `identity-audit`. `payment-methods` is present only when a consumer declares payments are required. Consumers may add tabs through `tpw_core_settings_tabs`; those tabs must use the same canonical base URL.

The Settings API endpoint `options.php` remains valid for forms that use WordPress Settings API submission; it is not an admin page route.

## Menu Ownership

iLungu Club Settings is visible only at **iLungu Club -> Settings**. Do not register an iLungu Club submenu beneath native WordPress **Settings** and do not use `add_options_page()` for this screen.

Existing wp-admin page slugs for Dashboard, Manage Members, Menu Permissions, System Pages, and other Club-owned screens remain stable unless a separately documented migration changes them.

## Legacy Compatibility

Legacy FlexiClub bookmarks may request the former `tpw-flexiclub-*` routes. Club retains hidden redirect-only registrations for `tpw-flexiclub-dashboard`, `tpw-flexiclub-settings`, `tpw-flexiclub-manage-members`, `tpw-flexiclub-gallery-admin`, `tpw-flexiclub-upload-pages`, `tpw-flexiclub-menu-manager`, and `tpw-flexiclub-logs`. The redirect preserves scalar routing context, including valid `tab`, workspace/action state, and member identifiers.

Legacy `/wp-admin/options-general.php?page=tpw-core-settings` remains a redirect-only compatibility endpoint to the canonical Club Settings route. It preserves scalar query context and retains `tab` only when that tab is currently registered.

Legacy routes are not visible menu items and must not be generated by new Club or consumer navigation.
